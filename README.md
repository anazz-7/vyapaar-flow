# Vyapaar Flow - Smart Business Khata & Day Book

A modern, fast, mobile-friendly Indian MSME business ledger, customer khata passbook, daily cash drawer (roker), payment recording, and instant receipt management web application.

## 🌐 Live Demo

- **GitHub Pages:** [https://anazz-7.github.io/vyapaar-flow/](https://anazz-7.github.io/vyapaar-flow/)

## ✨ Features

- **Customer Khata (Passbook):** Real-time balance calculation, overdue tracking, transaction timeline, and invoice history.
- **Daily Day Book (Roker):** Daily cash-in / cash-out drawer tracker with net balance calculation.
- **Payment Collection & Receipts:** Quick recording of Cash, UPI / QR, and Bank payments with thermal receipt printing and WhatsApp share.
- **Cash Denomination Counter:** Real-time physical currency note counter for closing drawers (₹500, ₹200, ₹100, etc.).
- **Mobile Frame Mode:** One-click toggle between responsive desktop and mobile viewport frame.

## 🛠️ Tech Stack

- **React 19**
- **Vite 8**
- **Tailwind CSS 4**
- **Lucide Icons & Material Symbols**
- **TypeScript**

## 💻 Local Development

1. Install dependencies:
   ```bash
   npm install
   ```

2. Run development server:
   ```bash
   npm run dev
   ```

3. Build production bundle:
   ```bash
   npm run build
   ```
